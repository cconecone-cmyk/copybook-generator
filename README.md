## ✨ 核心特色

### 🀄 中文方格描寫
- **多元開源中文字體庫**：
  - **硬筆楷書／教科書體**：標楷體（系統字型）、**芫荽體 Iansui**（符合台灣教育部標準字形之開源硬筆楷書，Google Fonts + jsDelivr CDN 雙備援）、**霞鶩文楷 TC**（開源行楷）、**Klee One 克莉體**（硬筆教科書楷體）。
  - **行書／手寫書法體**：**辰宇落雁體**（台灣手寫行書體）、**馬善政毛筆楷書**、**智芒星行書**、**龍藏體**、**鍾齊流江毛草**、**佑字體（Yuji Syuku）**。
  - **宋明／黑體**：思源宋體、思源黑體。
- **經典範例快速載入**：
  - 《陋室銘》（劉禹錫）
  - 《般若波羅蜜多心經》
  - 《弟子規　選讀》（總敘、入則孝、出則弟、謹、信、汎愛眾、親仁、餘力學文）
  - 《出師表》（諸葛亮經典全文）
- **版面與格線**：
  - A4 橫式／A4 直式。
  - 直排（右至左）／橫排（左至右）。
  - 田字格、米字格、方格、無格線，支援大／中／小格預設及 3～40 行列自訂。
- **智慧排版**：標點符號避頭點、半形標點轉全形、段落換行與段首空兩格、一行描寫一行空白模式。

### 𔤤 英文橫式練習
- **專屬三大練習模式**：
  1. **單字練習模式（描寫＋抄寫）**：每行輸入一個單字，支援附帶詞性與中文（例如 `family (n.) 家庭` 或 `apple | 蘋果`）。左側獨立呈現中文提示欄，四線格內重複 1～4 次灰底描寫，後方留白供學生自主抄寫！
  2. **課文／句子／歌詞模式（全部灰字描寫）**：內建智慧斷詞換行（Word-wrap，絕不從英文字母中間切斷），整篇以標準四線格呈現供學生全文描寫。
  3. **課文／句子／歌詞模式（一行描寫、一行空白抄寫）**：一行灰底句子描寫、下一行留白四線格供學生對照抄寫，最符合國中小英語習字需求。
- **英語格線樣式**：
  - **標準四線格（Four-line Stave）**：上線、中虛線（x-height）、**柔和紅基線（Baseline）**、下線，字母基線精準對齊第三線！
  - **雙線格／單行橫線格（Lined）**：簡潔橫線底格，適合進階整段英文抄寫。
- **開源英文字型庫**：
  - **教學印刷手寫體**：Andika（標準教學單層 a、g 印刷手寫體）、Comic Neue。
  - **自然手寫風格**：Patrick Hand、Caveat。
  - **連寫／草寫體（Cursive）**：Dancing Script、Playwrite US Trad（美式習字草寫體）。
  - **標準字體**：Noto Sans、Noto Serif。
- **精選英文範例**：
  - **國中七年級核心單字**（18 個核心高頻詞，附詞性與中文釋義）。
  - **披頭四經典名曲〈Let It Be〉**。
  - **披頭四經典名曲〈Here Comes the Sun〉**。

### 📋 課堂管理與輸出優化
- **抬頭資訊欄**：
  - 支援「姓名／座號／日期欄」。
  - **全新支援「家長簽名欄」**：勾選後自動調整欄位間距，A4 直式或橫式皆緊湊對齊不折行。
- **動態 PDF 檔名同步**：
  - 點擊「列印／另存 PDF」時，系統會自動將檔案名稱設定為 `標題(灰底字描寫本).pdf`，免去手動命名的繁瑣步驟。
- **列印建議**：
  - 列印或另存 PDF 時請選「縮放 100%」，並關閉瀏覽器的「頁首及頁尾」。
