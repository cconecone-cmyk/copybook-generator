# 灰底字描寫本生成器

貼上課文或古文，即可線上自動生成 A4 滿版灰底字描寫紙（硬筆字帖），支援直接列印或另存 PDF。

## 線上使用
👉 **[點此開啟灰底字描寫本生成器](https://cconecone-cmyk.github.io/copybook-generator/)**

## 功能特色
- **版面自由設定**：A4 橫式／直式、直排（右至左）／橫排（左至右）
- **多種格線**：田字格、米字格、方格、無格線，並內建大／中／小格快速預設與自訂行列數
- **字體與深淺**：支援標楷體、霞鶩文楷、思源宋體、思源黑體，可微調字體大小與灰階深淺
- **智慧排版**：標點符號避頭點、半形轉全形、段落換行與段首空兩格、一行描寫一行空白練習模式
